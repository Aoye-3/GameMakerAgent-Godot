# Studio Advisor Candidate

本目录是从首个 Godot 驱动项目中迁入的实验候选，不是 GameMakerAgent 已发布 Skill。

- `skill/`：Skill 主文件、按需顾问视角和宿主元数据；
- `evals/`：激活边界、低噪声和单一 Decision Card 行为用例；
- 来源与许可证见 [source intake manifest](../../../docs/research/source-intake-manifest.md)。

晋升前至少需要：

1. 所有静态行为用例可解析且保持激活边界；
2. 一次真实玩法讨论证明建议有用；
3. 一次普通实现请求证明 Skill 不进入开发上下文；
4. 一次试玩复盘证明它区分观察、解释和建议；
5. 宿主元数据去除项目专属假设。
