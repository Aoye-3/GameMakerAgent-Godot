# GameMakerAgent

GameMakerAgent 是从真实游戏项目中持续提炼的 Agentic Game Development
开发框架。当前首个驱动项目是独立仓库
[`Aoye-3/TapTapGameJam`](https://github.com/Aoye-3/TapTapGameJam)。

本仓库只保存可迁移、可复用、经过验证的框架能力，包括 Agent 编排、契约、
Godot 适配器、验证工具、知识资产和晋升流程；不保存具体游戏的玩法实现、
关卡、剧情或项目资产。

## 当前状态

项目处于框架基础阶段。先建立双仓边界、运行时契约、证据标准和晋升门禁，
再从 VibeGame 现有实现中分批提炼能力。
